#Игра для изучение осетинского языка

Название проекта: «Ирын» (от ирон. «æмбарын» — понимать / ирын — осетин)  
Платформа: ASP.NET Core (Web-приложение)  
Тип игры: кликер-тренажёр по поиску предметов на локациях

---

## Суть игры

Игроку последовательно показываются три уникальные локации (например: комната, кухня, двор).  
Под локацией выводится список слов на осетинском языке (существительные в единственном числе, без артиклей).  
Задача: найти и кликнуть на соответствующий предмет внутри интерактивной картинки локации.

Каждый правильный клик:
- отмечает слово в списке как найденное;
- добавляет визуальный фидбек (подсветка, галочка);
- воспроизводит произношение слова (опционально).

После нахождения всех слов из списка — игра переходит к следующей локации.

---

## Для чего нужна игра

- Запоминание базовой лексики осетинского языка через визуально-игровую ассоциацию.
- Развитие навыка распознавания слов без перевода на русский.
- Погружение в языковую среду через связку «слово → изображение → действие».
- Подходит для начального уровня (A1–A2).

---

## Целевая аудитория

- Дети от 7 лет и взрослые, начинающие изучать осетинский язык.
- Пользователи без технической подготовки (минимальный порог входа).
- Люди, интересующиеся культурой и языком осетин (в том числе диаспора).

---

## Структура локаций (пример)

Каждая локация включает:

1. Изображение (.jpg или .png).
2. JSON с зонами кликов (координаты + осетинское слово).
3. Список целевых слов (4–6 слов на локацию).

Пример локации «Кухня» (Хæдзар):

| Осетинское слово | Перевод        |
|------------------|----------------|
| ком              | нож            |
| афтаг            | тарелка        |
| бакал            | чашка          |
| уæлибар          | стол           |

---

## Требования к игре

### Обязательные функции

- [ ] Выбор первой локации автоматически при старте.
- [ ] Отображение текущей локации (картинка + название на осетинском).
- [ ] Список слов (неотмеченные — чёрным, отмеченные — серым с зачёркиванием или иконкой).
- [ ] Клик по правильному предмету:
  - слово отмечается найденным;
  - предмет на картинке получает кратковременную обводку/эффект;
  - звук «правильно» (опционально, но желательно).
- [ ] После нахождения всех слов — кнопка «Далее» (или автоматический переход через 2 сек).
- [ ] По завершении всех трёх локаций — экран победы с поздравлением на осетинском: «Фæзæрдын!» («Поздравляю!»).
